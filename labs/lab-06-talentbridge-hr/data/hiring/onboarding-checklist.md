## How to use this checklist

The Policy & Onboarding Specialist agent produces the onboarding plan for the successful
candidate from this template. Every item must end in an **observable state** — something a person
could confirm on the day. "Set up access" is not an item. "Ticketing system account created and
first login completed" is.

Items are grouped by when they must be complete.

## Rules that apply to the agent

- Refer to the candidate by `candidate_id` and pseudonym **only**. Never invent a real name.
- Never invent a credential, account name, licence key or system URL. Where one would be needed,
  write `<issued by IT Operations>`.
- Never record a protected characteristic. The right-to-work check in A2 is a single yes/no
  eligibility record and is never a scoring input.
- Every deferred item must carry a reason and an owner. A silently dropped item is an audit gap.
